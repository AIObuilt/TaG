# TaG v0.1.0

TaG `v0.1.0` is the first public release of the source-available core for
governed AI execution.

## What this release establishes

- a clear product story for non-technical operators using AI coding agents
- local governance hooks for spending, credentials, QA, security, delegation,
  and completion claims
- a local-first routing baseline
- a governed read-only tool loop
- file-based persistent memory and session continuity primitives
- practical getting-started instructions for Claude Code, Codex CLI, and
  generic agent runtimes

## Why it matters

Most AI tools are easy to start and hard to trust. TaG is the layer that makes
AI usable in the real world by enforcing scope, verification, and operational
discipline before an agent can claim completion.

The commercial wedge is straightforward:

Non-coders can build and ship with AI agents when execution is governed.

## Included in this release

- `tag/` source-available governance core
- `agent-enforcement/` tests covering hooks, policy, routing, and runtime
  controls
- root `LICENSE`, `SECURITY.md`, and `CHANGELOG.md`
- minimal `pyproject.toml` packaging metadata for install confidence
- reproducible governance demo:
  `docs/demo/60-second-governance-demo.md`
