# Security Policy

## Reporting a Vulnerability

If you believe you have found a security issue in TaG, do not open a public
issue first.

Report it privately with:

- a clear description of the issue
- affected hooks, files, or runtime surfaces
- reproduction steps or a proof of concept
- expected impact

Send reports to `vance@aiobuilt.co`.

## What to Expect

- Initial acknowledgment target: 3 business days
- Triage target: 7 business days
- Coordination on remediation and disclosure before public release

## Scope

This policy covers the TaG source-available core in this repository,
including:

- `tag/`
- `agent-enforcement/`
- `tag_config.py`
- local governance hooks, runtime policy, and verification surfaces
